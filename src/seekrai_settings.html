Atlassian API Token

Required

Personal API token for accessing Jira, Confluence, and other Atlassian services. This token is used to search and retrieve data from your Jira tickets and projects.

For your security, tokens can last no longer than 90 days. When generating your token, you'll set an expiry date. Enter that same expiry date below.

Your Red Hat email is automatically populated from your Kerberos username. This is used to validate your Atlassian API token.

Don't have an API token? Generate one here

Important: Before generating your token, you must first select an expiry date (maximum 90 days from today). After generating the token, enter the exact same expiry date in the "Token Expiry Date" field below.

💡 Important: Enter the exact same date you selected when generating the token on Atlassian. Seekr validates your token every 24 hours to detect if it has been revoked or expired.

• Date entered BEFORE Atlassian expiry: Seekr will stop using your token early, even though it's still valid on Atlassian. You'll lose days of valid usage.

• Date entered AFTER Atlassian expiry: Seekr will detect the token is expired within 24 hours and show a notification in the bell icon. The token will be cleared automatically.

Example: If Atlassian says "Expires: Jun 23, 2026", enter 06/23/2026 here (not Jun 22 or Jun 24).

🔔 Auto-detection: Seekr checks your token every 24 hours against Atlassian's API. If revoked or expired, you'll see a notification and the token will be cleared.

Red Hat API Token

Required

API token for accessing Red Hat services including Salesforce (SFDC) and Knowledge Centered Service (KCS) databases. Used to search and retrieve customer cases, knowledge articles, and support documentation.

Important: Tokens are only displayed once during generation and are not stored by Red Hat. They will expire after 30 days of inactivity. Generate a new token if yours has expired.

Don't have an API token? Generate one here

Provides access to: Salesforce (SFDC) Knowledge Base (KCS)

💡 Auto-expiry: Red Hat API tokens automatically expire after 30 days. Seekr will notify you via the bell icon 7 days before expiry.

Slack API Tokens

Required

Slack workspace tokens for accessing Red Hat Enterprise Slack channels and threads. Requires both xoxc- (user token) and xoxd- (cookie token) for authentication.

How to Get Your Slack Tokens

Step 1: Open Red Hat Enterprise Slack

Step 2: Press F12 to open Developer Tools

Step 3: Click the Application tab (or Storage in Firefox)

Step 4 (xoxc token):
• Go to Application tab
• Expand Local Storage → https://app.slack.com
• Click on localConfig_v2
• In the value column, look for "teams", find the team with "name": "Internal Red Hat"
• Within that team, look for "token"
• The token value starts with xoxc-

Step 5 (xoxd token):
• Go to Application tab
• Expand Cookies → https://app.slack.com
• Find the cookie named d
• Copy its value (starts with xoxd-)

GitLab API Token

Personal Access Token for searching GitLab repositories and code. Works with gitlab.com and self-hosted GitLab instances.

How to Generate Your GitLab Token

Step 1: Go to Red Hat GitLab - Personal Access Tokens

Step 2: Click "Add new token"

Step 3: Give your token a name (e.g., "SeekrAI Search")

Step 4: Set expiration date (recommended: 90 days)

Step 5: Select scopes:
• read_api - Read access to API
• read_repository - Read access to repositories

Step 6: Click "Create personal access token"

Step 7: Copy the token immediately
• Token format: Alphanumeric
• Minimum length: 10 characters
⚠️ Important: The token is only shown once! Save it securely.

Step 8: Go to Active Tokens to view the expiration date
• Copy the expiration date shown in the "Expires" column
• Enter it in the "Token Expiry Date" field below
• SeekrAI will notify you before the token expires

Note: Tokens can expire. Enter the expiry date below so Seekr can notify you before it expires.

Check Active Tokens for the expiration date, then enter it here. Seekr will notify you before it expires.
